# So these are the header files that I use in my daily basis, and I plan to make this repo about header files.
Currently we have header files for,
1. xx_gui - for simple gui in games. Uses SDL2 and SDL2_image. Feel Free to use it as you like or modify it. It uses bitmap for font rendering. and xx_gui/font1.png comes pre-included also, If you want to create your own bitmap fonts, please visit
https://aman-ido.github.io/
2. demos/xx_gui - has some code examples or programs made using xx_gui please feel free to look them.
